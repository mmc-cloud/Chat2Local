网页操作授权

可选择授权全部普通 HTTP/HTTPS 网站。全站模式下，移除单站记录不会排除该网站。
You can allow all ordinary HTTP/HTTPS websites. Removing an individual entry does not exclude it while all-site access is enabled.

填写一个网站地址并点击授权。权限范围为该协议和主机的所有路径与端口；不包含其他子域名。

本机连接权限不会自动授权操作本机网页，也需要在这里确认。

    标签分组授权 / Tab group access

    独立于网站授权。只有在这里点击授权后，MCP 才可查询或管理标签分组。

    书签授权 / Bookmark access

    独立于网站和标签分组授权。授权后 MCP 可以读取和管理书签；递归删除须先预览并在对话中确认。
